# Voicemeeter Slider Control

Управление параметрами Voicemeeter с физических потенциометров Arduino.

## Архитектура

Arduino отправляет значения потенциометров по USB/COM на 115200 бод. Приложение принимает последнюю полную строку, преобразует ADC 0–1023 в 0–100 %, затем в диапазон Voicemeeter -60…+12 dB и передаёт изменения в Voicemeeter Remote API.

## OSD

Версия текущей разработки: 0.0.7.

При изменении назначенного слайдера приложение показывает небольшую подсказку с названием Strip или Bus из Voicemeeter и текущим Gain в dB.

OSD:

- не получает фокус;
- не перехватывает мышь;
- не появляется в Alt+Tab;
- автоматически скрывается через короткое время после последнего заметного изменения;
- подгоняет ширину под текст и показывается на мониторе активного окна;
- отключается из меню в трее.

Обычный оконный и borderless fullscreen режимы поддерживаются. Эксклюзивный fullscreen не позволяет обычному внешнему Win32-окну гарантированно рисоваться поверх приложения; этот проект не использует инъекцию или графические хуки.

## Надёжность

- hot-plug COM через WM_DEVICECHANGE;
- watchdog и автоматическое повторное открытие COM-порта;
- безопасная обработка частичных serial-пакетов;
- обработчик данных больше не использует изменяющийся глобальный SerialPort для чтения;
- поток записи в Voicemeeter сериализован;
- несколько изменений объединяются в один SetParameters;
- одинаковые значения не отправляются повторно;
- после временного отключения Voicemeeter запросы автоматически повторяются без нового Login;
- конфигурация сохраняется через временный файл;
- старые конфигурации нормализуются при загрузке.

## Сборка

Требуется .NET 10 SDK.

Для portable single-file Windows x64:

dotnet publish VoicemeeterSliderControl.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false -p:DebugType=None -p:DebugSymbols=false -o publish

Voicemeeter устанавливается отдельно. DLL Remote API берётся из установленного Voicemeeter.
